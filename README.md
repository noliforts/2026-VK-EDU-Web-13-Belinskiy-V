# Qurilka — форум вопросов и ответов

Учебный проект VK Education (Web, ДЗ1): статическая вёрстка («рыба») сайта вопросов и ответов в стиле старых форумов. Реализован на Django: шаблоны лежат в `public/`, статика (CSS, картинки) хранится локально в `public/static/`. Все данные на страницах — заглушки.

## Как запустить

Нужен Python 3.10+.


```bash
# 1. создать и включить виртуальное окружение
python3 -m venv venv
source venv/bin/activate        

# 2. поставить зависимости
pip install -r requirements.txt

# 3. запустить сервер
python manage.py runserver
```

После запуска сайт доступен по адресу http://127.0.0.1:8000/.

## Страницы

| URL | Страница | Шаблон |
|---|---|---|
| `/` | список новых вопросов (index) | `public/index.html` |
| `/question/<id>/` | вопрос со списком ответов (например, `/question/1/`) | `public/question.html` |
| `/ask/` | форма создания вопроса | `public/ask.html` |
| `/login/` | форма входа | `public/login.html` |
| `/signup/` | форма регистрации | `public/signup.html` |
| `/profile/` | настройки профиля | `public/profile.html` |
| `/rules/` | правила | `public/rules.html` |
| `/help/` | помощь | `public/help.html` |

Общий каркас (шапка, сайдбар, подвал) лежит в `public/base.html`, остальные страницы наследуются от него.

## Шапка: авторизованный и неавторизованный вид

Шапка одна (`public/base.html`), её вид переключается флагом `is_auth`, который передаёт view. Настоящей авторизации пока нет, флаг стоит в `qurilka/views.py` как заглушка.

| Вид | Где показывается | Что в шапке |
|---|---|---|
| авторизованный | `/`, `/question/<id>/`, `/ask/`, `/profile/` | поиск, кнопка «Задать вопрос», аватар, имя, статус, «настройки», «выход» |
| неавторизованный | `/login/`, `/signup/`, `/rules/`, `/help/` | поиск, «Вход», «Регистрация» (без кнопки «Задать вопрос») |

Кнопка «Задать вопрос» доступна только в авторизованном виде шапки и ведёт на `/ask/`. «Выход» ведёт на `/login/` (неавторизованный вид), а «Войти» и «Зарегистрироваться» на страницах входа и регистрации ведут на `/` (авторизованный вид).
